PFAS Groundwater Contamination Risk Prediction

Developed and evaluated machine learning models using 26,900 California groundwater observations to predict high-risk PFAS contamination. Compared baseline and advanced models using ROC/AUC, F1-score, sensitivity, and confusion matrices, and applied SMOTE to address severe class imbalance.

Best model: Random Forest · 0.9818 AUROC · ~93% sensitivity · Supported prioritization of high-risk wells for groundwater testing.

R · Random Forest · SVM · kNN · Logistic Regression · SMOTE · caret · pROC · ggplot2

Movie Revenue Success Prediction (Deep Learning)

Built and compared a feedforward neural network against a logistic regression baseline to predict movie financial success using the TMDB 5000 Movie Dataset (~5,000 movies). Used pre-release features including budget, popularity, runtime, and vote average, with an 80/20 train-test split and standardized feature scaling.

Results: Neural network achieved 82.4% accuracy and 0.81 F1-score, outperforming the logistic regression baseline (80.2% accuracy) and demonstrating the value of nonlinear modeling for movie success prediction.

Python · TensorFlow/Keras · Scikit-learn · Pandas · NumPy · Google Colab

Group project (UTSA) — My Contributions: Feature standardization, baseline logistic regression implementation, feedforward neural network architecture and training, evaluation of the neural network using accuracy, precision, recall, and F1-score, comparison of neural network performance against the logistic regression baseline, and visualization of accuracy.

Dairy Queen Consumer Purchase Intention Analysis

Conducted multiple linear regression analysis on consumer survey data to identify factors influencing Dairy Queen customer purchase intentions. Tested marketing hypotheses related to pricing, menu diversity, and customer service to evaluate their impact on future purchasing behavior.

Key finding: Menu diversity was the only statistically significant predictor of purchase intention (p = 0.012), while pricing and customer service showed no significant relationship, providing actionable insights for marketing strategy.

SPSS · Multiple Linear Regression · Survey Analysis · Qualtrics · Excel
